# Migrate Public Folder Images to Cloudinary

The public folder contains ~71 large image files (JPG, PNG, HEIC) causing slow renders and Vercel deployment failures. We'll create an automated upload script and replace all local image references with hardcoded Cloudinary URLs.

## Proposed Changes

### 1. Upload Script

#### [NEW] [upload-to-cloudinary.mjs](file:///c:/Users/moncefyak/Desktop/cic-2026-2027/Cic-reg-frontend/scripts/upload-to-cloudinary.mjs)

A Node.js script your friend runs **once** on the machine that has the `public/` folder. It:

1. Walks the entire `public/` directory tree for image files (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.heic`)
2. Uploads each to Cloudinary using the **Upload API** (via the `cloudinary` npm package)
3. Sets the `public_id` to mirror the local path (e.g. `public/departments/HR.JPG` → `cic-frontend/departments/HR`)
4. Outputs a JSON mapping file `scripts/cloudinary-map.json` mapping every original local path (e.g. `/departments/HR.JPG`) to its Cloudinary delivery URL
5. Skips already-uploaded files if re-run (idempotent)

> [!IMPORTANT]
> The `CLOUDINARY_URL` env variable must be set before running. Your friend runs:
> ```bash
> npm install cloudinary   # one-time
> node scripts/upload-to-cloudinary.mjs
> ```

### 2. URL Map Generator

#### [NEW] [generate-image-urls.mjs](file:///c:/Users/moncefyak/Desktop/cic-2026-2027/Cic-reg-frontend/scripts/generate-image-urls.mjs)

After upload, this second script reads `cloudinary-map.json` and **generates a static JS module** at `src/assets/data/cloudinaryUrls.js` containing a simple object mapping local paths → Cloudinary URLs. This is what the frontend imports — **no backend needed, no runtime API calls**.

---

### 3. Frontend Cloudinary URL Module

#### [NEW] [cloudinaryUrls.js](file:///c:/Users/moncefyak/Desktop/cic-2026-2027/Cic-reg-frontend/src/assets/data/cloudinaryUrls.js)

Auto-generated file exporting:
```js
// Auto-generated by scripts/generate-image-urls.mjs — do not edit manually
const CLOUDINARY_URLS = {
  '/CIC1.png': 'https://res.cloudinary.com/ccwsxvcg/image/upload/cic-frontend/CIC1',
  '/Hero.png': 'https://res.cloudinary.com/ccwsxvcg/image/upload/cic-frontend/Hero',
  '/departments/HR.JPG': 'https://res.cloudinary.com/ccwsxvcg/image/upload/cic-frontend/departments/HR',
  // ... all 71 images
};
export default CLOUDINARY_URLS;
export function cloudinaryUrl(localPath) { return CLOUDINARY_URLS[localPath] || localPath; }
```

A `cloudinaryUrl()` helper function lets any component convert a local path to the Cloudinary URL with a simple call. Falls back to the local path if not found.
